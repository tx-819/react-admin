# Menu route guard and 403 page — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For logged-in, non-super users inside `basicLayout`, allow only URLs whose normalized path appears in the user menu tree; otherwise show an Ant Design 403 `Result`. Respect `menuLoading` to avoid false 403; keep guest handling out of this guard.

**Architecture:** Pure helpers normalize paths and flatten `MenuRecord[]` into a deduped `allowedPathnames` array stored in `menuStore` whenever `setMenuList` runs. A `MenuRouteGuard` component wraps `useOutlet()` in `basicLayout`, reads `isLogin`, `isSuper`, `menuLoading`, `allowedPathnames`, and `useLocation().pathname`, and switches between outlet and `Forbidden403`. `useInitUser` clears menus on bootstrap failure; `clearAuth` clears menus on logout so stale trees are not shown.

**Tech stack:** React 19, React Router 7, Zustand, Ant Design 6, TypeScript, Vite.

**Spec:** `docs/superpowers/specs/2026-05-08-menu-route-403-design.md`

### Task 1: Path utilities

```typescript
import type { MenuRecord } from "@/api/permission";

/** Trim trailing slashes (except root) and ensure leading `/`. */
export function normalizeMenuPath(path: string): string {
  const trimmed = path.trim();
  const withSlash = trimmed.startsWith("/") ? trimmed : `/${trimmed}`;
  if (withSlash === "/") return "/";
  return withSlash.replace(/\/+$/, "") || "/";
}

/** DFS collect of every node's path in menu tree; normalize and dedupe (stable unique). */
export function collectNormalizedMenuPaths(menus: MenuRecord[]): string[] {
  const seen = new Set<string>();
  const out: string[] = [];

  const walk = (nodes: MenuRecord[]) => {
    for (const n of nodes) {
      if (n.path) {
        const p = normalizeMenuPath(n.path);
        if (!seen.has(p)) {
          seen.add(p);
          out.push(p);
        }
      }
      if (n.children?.length) walk(n.children);
    }
  };

  walk(menus);
  return out;
}
```

### Task 4: `MenuRouteGuard`

**Files:**
- Create: `src/layouts/basicLayout/_components/MenuRouteGuard.tsx`

- [ ] **Step 1: Implement guard**

```tsx
import { useLocation, useOutlet } from "react-router-dom";
import { useUserStore } from "@/store/userStore";
import { useMenuStore } from "@/store/menuStore";
import { normalizeMenuPath } from "@/utils/menuPaths";
import Forbidden403 from "@/components/Forbidden403";

const MenuRouteGuard = () => {
  const outlet = useOutlet();
  const { pathname } = useLocation();
  const isLogin = useUserStore((s) => s.isLogin);
  const isSuper = useUserStore((s) => s.isSuper);
  const menuLoading = useMenuStore((s) => s.menuLoading);
  const allowedPathnames = useMenuStore((s) => s.allowedPathnames);

  if (!isLogin) {
    return outlet;
  }

  if (menuLoading) {
    return outlet;
  }

  if (isSuper) {
    return outlet;
  }

  const normalized = normalizeMenuPath(pathname);
  if (allowedPathnames.includes(normalized)) {
    return outlet;
  }

  return <Forbidden403 />;
};

export default MenuRouteGuard;
```
